# 数据来源与校验规则

本 skill 只允许使用真实开奖数据。

- 不允许使用模拟数据
- 不允许在真实数据缺失时自行补全、猜测或降级生成
- 如果无法获取可校验的真实数据，必须直接终止

## 工具优先级

获取真实数据时，按以下优先级依次尝试：

1. `WebSearch`
2. `WebFetch`
3. `duckducksearch`
4. `tavily-search`

前一层级已经拿到可解析、可校验的数据时，不要无意义地继续降级到更低优先级。

## 数据源要求

- 优先官方或权威来源
- 必须清晰标注来源名称、来源 URL、抓取时间
- 除非已经实际抓取并完成解析，否则不得声称“最新开奖数据”

## 最小数据字段

每条开奖记录至少应包含：

- 期号
- 开奖日期或开奖时间（时区尽量明确）
- 前区 / 红球号码
- 后区 / 蓝球号码
- 来源名称
- 来源 URL
- 抓取时间

## 必须执行的校验

- 范围校验：号码必须位于对应彩票允许的数值范围内
- 数量校验：每期号码数量必须正确
- 唯一性校验：同一期内不得出现重复号码
- 结构校验：关键字段不得缺失
- 彩票类型校验：双色球与大乐透的结构不能混淆

## 推荐的交叉核对

- 尽可能使用至少两个真实来源交叉核对
- 如果两个来源在期号、日期或开奖号码上冲突，必须停止并报告冲突
- 不允许用“多数原则”直接猜测正确结果

## 失败处理

出现以下任一情况时，必须直接终止：

- 所有工具都无法拿到真实数据
- 抓取到的数据缺少关键字段
- 号码范围或数量不合法
- 多来源数据冲突
- 无法清晰标注来源信息
